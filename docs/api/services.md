# Сервіси Клієнта (Services)

Цей розділ містить документацію для сервісів, які забезпечують мережеву взаємодію, логування, роботу з апаратурою та іншими системними функціями.

## PiNetworkService
Основний мережевий сервіс для зв'язку з Raspberry Pi.
::: app.services.pi_network_service

---

## JammerService
Сервіс керування апаратними реле (Jammer, Сирена тощо).
::: app.services.jammer_service

---

## RecordingService
Сервіс запису аудіо/відео потоків детекцій.
::: app.services.recording_service

---

## LogService
Сервіс для запису подій детекції та дій оператора.
::: app.services.log_service

---

## MapService
Сервіс для отримання та обробки тайлів мапи.
::: app.services.map_service

---

## DetectionBackgroundService
Обробка фонових сигналів для аналізу завад.
::: app.services.detection_background_service

---

## NetworkSignalService
Сервіс моніторингу якості з'єднання Ethernet/WiFi.
::: app.services.network_signal_service

---

## UsbAuthService
Сервіс автентифікації за допомогою фізичних USB-ключів.
::: app.services.usb_auth_service

---

## MediaPlayerService
Сервіс для відтворення звукових тривог та записів.
::: app.services.media_player_service

---

## SystemService
Взаємодія з операційною системою (ОС, файли, процеси).
::: app.services.system_service

---

## KeyboardService
Віртуальна клавіатура для сенсорних екранів.
::: app.services.keyboard_service

---

## SettingsService
Керування конфігурацією додатку.
::: app.services.settings_service

---

## CleanerService
Автоматичне очищення старих медіафайлів та логів.
::: app.services.cleaner_service
