# Допоміжні утиліти (Utils)

Бібліотеки загального призначення, які використовуються у різних частинах проекту для математичних обчислень, роботи з геопозицією та асинхронністю.

---

## ChartMath
Математичні функції для обробки даних спектру та графіків.

::: app.utils.chart_math

---

## GeoUtils
Функції для роботи з координатами, розрахунку азимутів та відстаней.

::: app.utils.geo_utils

---

## AsyncUtils
Допоміжні обгортки для синхронізації асинхронного коду Python з циклами подій Qt.

::: app.utils.async_utils

---

## PasswordUtils
Функції для безпечного хешування та перевірки паролів.

::: app.utils.password_utils

---

## UIUtils
Допоміжні функції для роботи з віджетами, стилями та форматуванням тексту в UI.

::: app.utils.ui_utils

---

## ConvertMeasurementUnit
Конвертація одиниць вимірювання (частота, потужність, відстань).

::: app.utils.convert_measurement_unit
