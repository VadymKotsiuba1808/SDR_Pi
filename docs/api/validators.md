# Валідатори (Validators)

Модулі для перевірки коректності введених даних користувачем перед їх обробкою або збереженням.

---

## BaseValidator
Базовий абстрактний клас для створення власних валідаторів з підтримкою ланцюжків перевірок.

::: app.validators.base_validator

---

## PasswordValidator
Спеціалізований валідатор для перевірки складності та коректності паролів. Перевіряє довжину, наявність цифр, спецсимволів та відповідність політиці безпеки.

::: app.validators.password_validator
