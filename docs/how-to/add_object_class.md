# Як додати новий клас об'єкта (БПЛА)

Система **SDR_Pi** використовує базу даних сигнатур для ідентифікації виявлених сигналів. Якщо ви хочете, щоб система розпізнавала нову модель БПЛА, вам потрібно додати відповідний клас об'єкта.

---

## 🛠 Крок 1: Відкриття менеджера класів

1.  Запустіть клієнтський додаток.
2.  Перейдіть до меню **"Налаштування"** або натисніть кнопку **"Менеджер об'єктів/класів"** на головній панелі (залежно від версії інтерфейсу).
3.  Оберіть вкладку **"Класи об'єктів"**.

## 📝 Крок 2: Введення даних

Натисніть кнопку **"Додати новий"** та заповніть наступні поля:

*   **Назва класу:** (наприклад, `Mavic 3`, `Orlan-10`).
*   **Діапазон частот (MHz):** Вкажіть центральну частоту та ширину смуги, на яких працює пульт керування або передавач відео даного БПЛА.
*   **Тип сигналу:** Оберіть із випадаючого списку (FHSS, Аналогове відео, OFDM тощо).
*   **Рівень загрози:** Встановіть від 1 (низький) до 5 (критичний).

!!! tip "Важливість точності"
    Точність введених частот безпосередньо впливає на ймовірність правильної детекції Обчислювальним модулем.

## 💾 Крок 3: Збереження та синхронізація

1.  Натисніть кнопку **"Зберегти"**.
2.  Клієнт автоматично відправить запит на Сервер (`pi_server`).
3.  Сервер оновить свою внутрішню базу даних SQLite.
4.  Обчислювальний модуль (DSP) миттєво почне використовувати нову сигнатуру для порівняння в реальному часі.

---

## 🔄 Редагування та видалення

Ви завжди можете змінити параметри існуючого класу або видалити застарілі сигнатури через цей же інтерфейс. Зміни вступають в силу миттєво після натискання кнопки "Оновити".
