# Багатомовність та Переклад (i18n)

Система **SDR_Pi** повністю підтримує багатомовність. Наразі доступні дві локалізації: **Українська** (основна) та **Англійська**.

---

## 🌍 Як змінити мову в додатку

1.  Запустіть клієнт.
2.  На головній панелі керування (справа зверху) знайдіть випадаючий список вибору мови.
3.  Оберіть потрібну мову зі списку (Українська або Англійська).
4.  Додаток миттєво оновить всі написи без необхідності перезавантаження (завдяки події `changeEvent` та методу `retranslateUi`).

---

## 🛠 Процес перекладу (для розробників)

Додаток використовує стандартний механізм **Qt Linguist**.

### 1. Файли перекладів
Усі переклади знаходяться в директорії `app/i18n/`:
*   `app_uk.ts` — вихідний файл для української мови (XML формат).
*   `app_en.ts` — вихідний файл для англійської мови.
*   `qm/*.qm` — скомпільовані бінарні файли, які використовує програма під час роботи.

### 2. Оновлення перекладів
Якщо ви додали нові рядки в коді за допомогою `self.tr("Текст")` або в `.ui` файлах:

```bash
# Оновлення .ts файлів (збір нових рядків з коду)
pyside6-lupdate . -ts app/i18n/app_uk.ts app/i18n/app_en.ts

# Компіляція .qm файлів (після завершення перекладу)
pyside6-lrelease app/i18n/*.ts
```

### 3. Робота в Qt Linguist
Для зручного редагування використовуйте графічну утиліту **Qt Linguist**. Вона дозволяє бачити контекст кожного рядка та перевіряти статус перекладу.

---

## 💡 Кращі практики (Best Practices)

*   **Динамічні рядки:** Завжди використовуйте `self.tr()` для тексту, який бачить користувач.
*   **Контекст:** Якщо слово має кілька значень, додавайте коментар для перекладача: `self.tr("Open", "Menu command")`.
*   **Форматування:** Використовуйте плейсхолдери для змінних: `self.tr("Виявлено %1 об'єктів").arg(count)`. Це дозволяє правильно враховувати особливості граматики різних мов.
