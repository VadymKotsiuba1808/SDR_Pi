# SDR_Pi: Система Радіомоніторингу та Детекції

Ласкаво просимо до офіційної документації програмного комплексу **SDR_Pi**.

Цей проект представляє собою Модуль Оператора (Клієнтський Інтерфейс) для апаратно-програмного комплексу пасивного радарного виявлення БПЛА. Він забезпечує візуалізацію радіоспектрів, відображення виявлених цілей на карті, ведення журналів подій та взаємодію з Обчислювальним модулем (Raspberry Pi) через пряме Ethernet-з'єднання.

## Основні можливості

*   🖥️ **Сучасний Графічний Інтерфейс:** Розроблений на базі `PyQt6` з використанням апаратного прискорення для плавної відмальовки графіків (`pyqtgraph`).
*   ⚡ **Низька затримка:** Використання асинхронних TCP-сокетів (`qasync`) для миттєвої реакції на події від Обчислювального модуля.
*   🗺️ **Картографія:** Візуалізація виявлених об'єктів на цифровій карті в реальному часі.
*   🛡️ **Система реагування:** Підтримка відправки команд на керовані виходи (Jammer, Реле).
*   📊 **Гнучка система логування:** Збереження історії детекцій та дій користувача у локальні файли `JSONL`.
*   🛠 **Кастомізація:** Можливість додавання нових класів БПЛА (сигнатур) через вбудований менеджер.

## Структура Документації

Документація побудована за фреймворком **Diátaxis** і розділена на чотири основні блоки:

1.  **Огляд Системи:** Загальна [Архітектура](architecture.md) комплексу та інструкції з [Розгортання](installation.md).
2.  **Посібники (How-to):** Практичні кроки для виконання конкретних завдань оператором або розробником.
3.  **API Довідник (Клієнт):** Автоматично згенерована документація для класів та методів клієнтського додатку (`app/`).
4.  **API Довідник (Сервер):** Автоматично згенерована документація для заглушок TCP-сервера та модуля бази даних SQLite (`temp/`).

## Швидкий старт для розробників

Для швидкого локального запуску із використанням симулятора (без реального обладнання):

```bash
# 1. Клонування репозиторію
git clone <url-репозиторію>
cd SDR_Pi

# 2. Створення віртуального середовища та його активація
python -m venv .venv
source ./.venv/Scripts/activate  # Для Windows (Git Bash)

# 3. Встановлення залежностей
pip install pip-tools
make deps

# 4. Запуск (рекомендується в різних вкладках терміналу)
python -m temp.populate_db_util   # Підготовка тестової БД (одноразово)
python -m app.utils.dummy_sender  # Симулятор даних (Raspberry Pi)
python main.py                    # Головний додаток
```

> **Детальніше:** Повні інструкції, включаючи налаштування для реального Raspberry Pi, читайте у розділі [Розгортання та Налаштування](installation.md).
