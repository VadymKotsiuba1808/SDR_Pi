# Розгортання та Налаштування

Цей посібник допоможе вам налаштувати середовище та запустити клієнтську частину системи **SDR_Pi** (Модуль Оператора).

---

## 📋 Системні Вимоги

| Компонент   | Вимога                                            |
| :---------- | :------------------------------------------------ |
| **ОС**      | Windows (рекомендовано Git Bash), Linux або macOS |
| **Python**  | 3.10+ (рекомендовано 3.12 або 3.13)               |
| **Пакети**  | `pip-tools`                                       |
| **Утиліти** | `make`                                            |

!!! tip "Встановлення `make` на Windows"
    Якщо `make` не встановлено, скористайтесь пакетним менеджером Chocolatey. Відкрийте PowerShell від імені адміністратора та виконайте:
    ```powershell
    choco install make
    ```

## ⚙️ Встановлення та Налаштування

### 0. Клонування репозиторію

```bash
git clone <URL_РЕПОЗИТОРІЮ>
cd SDR_Pi
```

### 1. Створення віртуального оточення

Рекомендується використовувати віртуальне середовище для ізоляції залежностей.

```bash
# Створення (один раз)
python -m venv .venv

# Активація — Windows (Git Bash)
source ./.venv/Scripts/activate

# Активація — Linux / macOS
source .venv/bin/activate
```

### 2. Встановлення залежностей

Проект використовує `pip-tools` для управління залежностями та `Makefile` для спрощення команд.

```bash
# Встановлення pip-tools
pip install pip-tools

# Встановлення всіх залежностей (production + dev)
make deps
```

### 3. Налаштування конфігурації

Відкрийте файл `config.ini` у корені проекту (або створіть його, якщо він відсутній). Для першого запуску достатньо налаштувати лише базові параметри підключення та мову:

```ini
[pinetwork]
pi_target_ip=192.168.0.162  # IP-адреса Raspberry Pi або пристрою із симуляцією
pi_target_port=6000         # TCP порт (за замовчуванням 6000)

[ui]
lang_code=uk                # Мова інтерфейсу (uk або en)

[maps]
api_key=Ваш_ключ_за_потреби # API ключ для картографії (якщо використовується)
```

!!! tip "Налаштування через Інтерфейс"
    Усі інші параметри (управління реле, таймери очищення, радіодіапазони тощо) **значно зручніше** налаштовувати безпосередньо через графічний інтерфейс програми, натиснувши на кнопку «Меню». Програма сама правильно згенерує та збереже повний `config.ini`.

## 🚀 Запуск (Development Mode)

Для локального запуску та тестування без реального заліза використовується симулятор (`dummy_sender`) та локальна база даних SQLite.

!!! note "Примітка"
    Рекомендується використовувати окремі вкладки терміналу для кожного кроку. Не забудьте активувати `.venv` у кожній з них!

### Крок 1 — Підготовка БД (одноразово)

Скрипт наповнює локальну SQLite базу тестовими даними. Виконується одноразово або при зміні моделей даних.

```bash
python -m pi_server.populate_db_util
```

_(Примітка: якщо виникає помилка `ModuleNotFoundError`, переконайтеся, що ви запускаєте з кореневої папки з прапорцем `-m`)._

### Крок 2 — Запуск симуляції (Dummy Sender)

Цей скрипт емулює роботу віддаленого Raspberry Pi, надсилаючи фіктивні дані про цілі в додаток по TCP.

```bash
python -m app.utils.dummy_sender
```

### Крок 3 — Запуск головного додатку

Запускає графічний інтерфейс користувача.

```bash
python main.py
# або
py main.py
```

## 🍓 Робота з реальним обладнанням

Якщо у вас є підключений до мережі Обчислювальний модуль (Raspberry Pi з SDR-аналізатором):

1. Переконайтеся, що Raspberry Pi запущений та доступний у мережі.
2. Вкажіть правильну IP-адресу вашої Raspberry Pi у полі `pi_target_ip` файлу `config.ini`.
3. Запустіть лише головний застосунок:

```bash
source ./.venv/Scripts/activate
python main.py
```
