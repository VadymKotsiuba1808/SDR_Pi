# Розгортання та Налаштування

Цей посібник допоможе вам налаштувати середовище та запустити всі компоненти системи **SDR_Pi**.

---

## 🖥️ Встановлення Клієнта (Windows/Linux)

Клієнтський додаток розроблений на базі Python та PyQt6. Він може працювати на будь-якій системі, де встановлено Python 3.12+.

### 1. Підготовка середовища
Рекомендується використовувати віртуальне середовище для ізоляції залежностей.

```bash
# Клонування репозиторію
git clone <URL_РЕПОЗИТОРІЮ>
cd SDR_Pi

# Створення та активація venv
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate
```

### 2. Встановлення залежностей
Ми використовуємо `pip-tools` для керування залежностями. Ви можете встановити їх за допомогою `Makefile` або напряму через `pip`.

```bash
# Через Makefile (рекомендовано)
make sync

# Або вручну
pip install -r requirements.txt
pip install -r requirements-dev.txt
```

### 3. Налаштування підключення
Відкрийте файл `config.ini` у корені проекту та вкажіть параметри вашої системи:

```ini
[Network]
server_ip = 192.168.1.100  # IP-адреса вашої Pi
server_port = 8080         # Порт TCP сервера

[General]
language = uk              # Мова інтерфейсу (uk/en)
debug_mode = false         # Режим розробника (додаткові логи)

[Storage]
log_retention_days = 30    # Скільки днів зберігати журнали детекцій
```

## 🍓 Налаштування Сервера (Raspberry Pi)

Серверний модуль (`pi_server`) повинен бути розгорнутий на Raspberry Pi, до якої підключено SDR-обладнання.

### 1. Системні вимоги
*   Raspberry Pi 4 або 5 (рекомендовано 4GB+ RAM).
*   ОС: Raspberry Pi OS (64-bit).
*   Встановлені драйвери для Pluto SDR (Libiio).

### 2. Запуск сервера
Ви можете запустити сервер як окремий процес:

```bash
# Перейдіть у папку проекту на Raspberry Pi
python -m pi_server.run_server
```

!!! tip "Автозапуск"
    Для промислового використання рекомендується налаштувати `systemd` сервіс для автоматичного запуску `run_server.py` при завантаженні системи.

---

## 🛠️ Перевірка розгортання

Для того, щоб переконатися, що все налаштовано правильно:

1.  Запустіть сервер на Raspberry Pi або локально: `python -m pi_server.run_server`.
2.  Запустіть клієнт: `python main.py`.
3.  Перевірте статус підключення у верхньому правому куті інтерфейсу. Зелений індикатор означає успішне з'єднання по Ethernet.
4.  Виконайте `make check`, щоб переконатися, що всі системні перевірки (лінтери, типи) проходять успішно.
