# План розвитку (Roadmap)

Проект **SDR_Pi** постійно розвивається. У цьому розділі наведені пріоритетні напрямки майбутніх розробок та вдосконалень.

---

### 🧠 Інтелектуальний аналіз (AI/ML)

- **Класифікація сигналів за допомогою ШІ:** Впровадження нейронних мереж (CNN) для автоматичного розпізнавання типів БПЛА на основі форми спектру, а не лише частотних сигнатур.
- **Детекція аномалій:** Система зможе попереджати про підозрілі сигнали, яких ще немає у базі даних.

### 📊 Робота з даними

- **Міграція на SQL для логів:** Перехід від JSONL-файлів до повноцінної локальної бази даних (наприклад, PostgreSQL або DuckDB) для швидкого виконання складних аналітичних запитів.

### 🛡️ Протидія (Реле / Jammer)

- **Розумне придушення:** Адаптивна зміна частоти роботи реле (Jammer) залежно від частоти, на якій було виявлено ціль (Reactive Jamming).
- **Інтеграція з пеленгаторами:** Використання кількох обчислювальних модулів для точного визначення місцезнаходження джерела сигналу методом тріангуляції.
